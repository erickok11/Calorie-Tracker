# CalorieTracker

A simple nutrition tracking app built with React Native and Expo.

CalorieTracker helps users track their daily calorie and protein intake,
set personalized nutrition goals, and review their progress over time.

## Current Features

- Daily calorie tracking
- Daily protein tracking
- Custom calorie and protein goals
- Food logging with amount and units
- Edit and delete food entries
- Nutrition progress ring
- History calendar
- Daily goal history
- Persistent local storage using SQLite
- Saved Foods/ Recent Foods logging
- Food Search in saved food
- Unit conversion
- Edit and delete saved food

## Development

Install dependencies

```bash
npm install
```

start the development server:

```bash
npx expo start
```

Run tests:

```bash
npm test
```
